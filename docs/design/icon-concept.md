# Icon provenance

The installed icon is [resources/icon.png](../../resources/icon.png). It is used by the AppImage and desktop launcher.

- Generated on 2026-09-04 as a mail-envelope variation of the [Omarchy brand mark](https://omarchy.org/brand/).
- Uses the square maze geometry with an inset envelope, Tokyo Night lavender `#bb9af7`, and navy `#1a1b26`.
- The selected design replaced an earlier blue concept. Unused concept previews and generation prompts are omitted from this repository.
- The launcher uses its installed PNG directly to avoid a stale themed icon.
